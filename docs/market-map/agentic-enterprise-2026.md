# Agentic Enterprise 2026 Market Map

The winning enterprise agent pattern is no longer "LLM plus tools." It is a governed harness: durable state, typed tools, approvals, identity, memory, observability, and evals around model calls.

## Market Thesis

Dark Factory OS is built around the shift from copilots to control planes. AI transformation work now requires teams to answer harder questions:

- Who or what is allowed to act?
- Which tools can be used without approval?
- Which memories are trusted?
- How are costs and outcomes measured?
- How does the system recover after failures?
- How does the organization reuse skills across domains?

## Reference Product Analogues

| Product pattern | What Dark Factory OS learns from it |
|---|---|
| Shopify Sidekick | Domain-native business context and admin actions |
| Ramp finance agents | Policy-aware spend governance and approvals |
| OpenAI/Google/Microsoft agent platforms | Managed agents need tools, identity, traces, and evals |
| Hermes/OpenClaw-style agents | Persistent memory, skills, scheduled work, and learning loops |
| Obsidian second brain | Durable knowledge graph and human-readable institutional memory |

## Differentiator

Most public repos show a single assistant. Dark Factory OS shows an enterprise operating model: one platform, three verticals, governed autonomy, measurable outcomes, and a path from research to runnable product.
